# 无外部 GDAL/CTB 服务的生产化实施计划

## 约束与完成定义

生产不依赖 GDAL CLI/Python 库或外部 CTB 服务；保留进程内 Cython/C++ 扩展及 pyproj、tifffile。开发测试用固定 GDAL/CTB 作独立参考。遵循“项目能力等效”，不重建完整 GDAL 驱动集合。

建议预算 80–125 人日。阶段完成必须有证据；代码合入或测试通过不自动等于生产验收。切片目标：同一输入、CPU、质量、压缩、持久化语义下三轮以上中位耗时不超过 main 的 1.2 倍；尚未达标时保留明确差距。持续压力及 Cesium 实际加载验收不得由单元测试代替。

## 实施顺序与状态

| 阶段 | 交付 | 状态 |
|---|---|---|
| A | 固定输入哈希的成对切片基准、阶段计时 | 完成首轮三样例、三轮基准 |
| B | 海底边缘采样、有效性与共享边修复 | 已落地全局供值点；n0e0 z10 覆盖外深裂缝消除，端点加密检查最大差 0.119m；根交界/混合 LOD 仍待验收 |
| C | Mercator 元数据、Heightmap 越界、参数能力、根瓦片 | 已加固固定 Cesium 1.120 消费路径；空根二进制 horizon 仍未解决 |
| D | 样本与解码复用、内存预算、并发性能 | 已消除邻瓦片重复采样；最新同期耗时为 main 的 1.10×/1.05×/1.14×，本轮达标但跨轮波动及长期容量仍待验收 |
| E | 输入边界、失败恢复、发布完整性 | 已有签名断点、损坏瓦片重算、失败无 layer；全矩阵及崩溃长稳待验收 |
| F | 扩展样本、长稳压测、浏览器与生产验收 | Cesium 双根 worker 与 180 帧 WebGL 冒烟通过；完整视觉/剔除、长稳仍待验收 |

每轮更新结果文档，记录实际运行配置、输入/二进制版本、耗时、体积和准确度；历史结果保留，不覆盖为新版本结果。外部依赖只进入测试环境。

## 首轮实施与验收

使用 `benchmarks/benchmark_tiling_production.py` 对两引擎传入同一个 main 预处理 TIFF（含内部概览），隔离文件布局和预处理差异。单进程独立输出，记录 SHA256、墙钟、分线程阶段累计时间及调用数。各阶段有嵌套关系，累计时间不能求和作为总时间。

优先修复具备独立反例的行为；不将未经验证的边界外推或 horizon 常数替代作为生产补丁。未完成事项持续列入此表。

本轮落地结果见 [实施记录](TERRAIN_PRODUCTION_IMPLEMENTATION.md)。外边缘支撑仅完成三样例有限验证，生产验收状态仍为 false；不宣称上述计划全部完成。

后续迭代见 [共享边与 Cesium 加固记录](TERRAIN_SHARED_EDGE_RESULTS.md)。下一步依次处理：边界外有效性与跨层衔接；根瓦片通用交换协议；在固定精度门槛下压缩网格及 I/O/调度开销；输入矩阵、故障恢复和长稳验收。不得通过放宽精度或取消持久化保障来单独追求耗时数字。

第三轮已完成 [覆盖外供值一致性修复和全层级审计](TERRAIN_GLOBAL_SUPPORT_RESULTS.md)。下一步先制定并验证根交界及混合 LOD 的连续性策略：区分原始几何误差与 Cesium 裙边遮挡效果，再决定父子边界约束；不能通过把深海边缘置零来通过接缝检查。
