# 第三轮：覆盖外供值一致性与跨层审计

2026-09-03，延续 main-zy 工作树；本轮生产路径没有增加 GDAL 或外部 CTB 依赖。未提交、未部署，生产就绪状态仍为 false。

## 修复

上一轮 n0e0 z10 全域接缝最大高差约 5224.52m。原因是外推只从当前瓦片内部取供值点：如果相邻瓦片的整条采样带位于源范围外，它没有供值点，最终回退到 0m，而另一侧保留深海高度。

`sample.py` 将规则改为在当前层级全局采样网格上选取最近的源支持点。供值点可以位于当前瓦片外；相同地理采样点不再因瓦片所有权不同而选择不同规则。已存在的有效采样保持不变，只补源范围外的无效采样，内部 NODATA 不填充。

优先复用瓦片已采样区域，仅确有必要时补采边界条带；条带强制使用原瓦片选择的概览，避免因条带只有一行/列而误用原图。没有可用供值点的粗层级保留原行为并列为未完成项。支持范围明确限定为同 CRS、正向 X/负向 Y、无旋转的矩形源；不将该规则扩展到未经验证的投影覆盖形状。

供值是覆盖外外推，不是观测数据；layer.bounds 仍保留真实源范围。签名改为 `terrain-v4-global-support`，不允许断点续跑混用旧采样结果。

## 验证结果

完整测试 **184 passed**，2 条第三方弃用警告；新增 25 项回归覆盖四方向、nearest/bilinear/average、有无概览和内部 NODATA。静态检查通过。

三个实际样例分别输出 1164、1164、1220 个瓦片，全部可独立解码并含法线，路径集合与 main 一致，三轮瓦片哈希一致。s85e80 和 s5e130 的全部瓦片哈希与上一轮一致；n0e0 内部参考 RMSE 仍为 17.38661m，边界参考最大误差仍为 188.77052m。

旧评估器的 z10 全域接缝口径下，n0e0 最大高差 **5224.51604 → 0.10411m**，接缝 RMSE **578.71208 → 0.01141m**。其输出由 1570690 增至 1600469 字节，约增加 1.90%。保留旧指标方便历史比较，不以有限取样结果冒充连续曲面误差上界。

新增 `audit_tile_seams.py` 检查 z0–z10，每条边包括端点在内取 33 个点，独立解码比较同层与相差一级的邻接网格，同时分开记录真实源有效区和全域。

| 样例 | z10 同层全域最大差 main / 当前 (m) | z10/z9 混合有效区最大差 main / 当前 (m) |
|---|---:|---:|
| s85e80 | 0.08162 / 0.00073 | 17.34992 / 17.34992 |
| s5e130 | 69.49370 / 0.11914 | 242.64183 / 146.39603 |
| n0e0 | 5191.47925 / 0.11881 | 225.17532 / 148.04852 |

加密口径包含端点，因此与旧口径的 0.10411m 并不矛盾。n0e0 混合全域最大差 main 为 5352.88983m，当前为 154.96070m。跨层存在不同采样足迹、概览和简化误差，本轮仅量化这些差异，尚未实现跨层严格连续。以上比较的是原始地形表面，不包括 Cesium 运行时裙边；不能据此直接判断屏幕上一定有或没有可见裂缝。

**根交界仍未解决**：三个样例 z0 的真实源支持根瓦片与合成零高度根瓦片存在约 2410–4455m 高差；非有限 horizon 也仍存在。不能把 z10 改善概括为“全层级无缝”。

## 同期三轮性能

两分支读取同一个 main 预处理 TIFF，4 CPU、4 线程、512MiB、65×65、geodetic、average、qfactor=1、法线、z10→0。每个进程串行执行，交替顺序，无诊断插桩；耗时不含容器启动，不清理操作系统缓存，两实现保留各自的持久化语义。

| 样例 | main 中位秒 | 当前中位秒 | 当前/main | 当前 RSS 中位 MiB |
|---|---:|---:|---:|---:|
| s85e80 | 1.71149 | 1.88124 | 1.099 | 229.04 |
| s5e130 | 1.77388 | 1.85910 | 1.048 | 152.39 |
| n0e0 | 1.81138 | 2.07065 | 1.143 | 231.37 |

本轮三个样例中位数满足 1.2× 目标，但 n0e0 当前单轮为 1.183–2.266 秒，且历史轮有未达标结果。不能将比值改善全部归因于此次算法修改，也不能据此宣称生产容量稳定；本轮重点是消除明确的错误供值。

证据位于 `data/tiling_support_20260903/`：`timings.json`、`summary.json`、`accuracy.json`、`lod_seams.json`、`main_lod_seams.json`、`readiness.json`、`source_sha256.json`、`native_sha256.txt`。三轮完整输出保存在 Docker 数据卷 `/data/tiling_production/globalsupport{1,2,3}`，历史数据未覆盖。本轮没有重跑浏览器验收，未将上一轮浏览器结果复制为本轮通过证据。

复现：运行 `benchmarks/run-tiling-edge-rounds.ps1 -RunPrefix <新前缀>`，再用验证镜像执行 `audit_tile_seams.py <前缀>1` 及 `--branch main`，最后执行 `export_tiling_production.py --prefix <前缀>`，挂载新的导出目录。源码、样例、数据卷映射沿用基准脚本；已有目录会拒绝覆盖。
