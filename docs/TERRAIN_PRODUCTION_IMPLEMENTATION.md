# 地形引擎生产化：首轮代码落地与验收记录

日期：2026-09-03。工作区基于 main-zy ddd0a17，保留既有未提交修改。本轮只修改工作区及隔离开发镜像/测试卷，没有部署或重启服务。

## 本轮变更

1. **成对基准与定位**：新增 `benchmark_tiling_production.py`，两引擎读取完全相同、SHA256 相同的 main 预处理 TIFF（含内部概览）。可选 `--profile` 提供嵌套阶段累计线程耗时，默认关闭，避免把当前独有插桩开销计入公平性能比较。
2. **样本网格复用**：新增每任务有界 LRU、single-flight 缓存，同坐标并发只计算一次；结果只读，Cython 入口改为 const memoryview。缓存占任务预算四分之一，reader 合计占一半，剩余为有界任务估算；线程数也受任务工作集估算约束。预算不是硬 RSS 限制，最小工作块及第三方分配仍有额外开销。保留每瓦片 fsync，不以取消同步写出制造加速。
3. **外边缘支撑**：同 CRS、北向输入，对位于源覆盖外且无效的采样使用最近采样边缘支撑，防止 mesh 内部受 0 m 外部顶点拉高。源内 NODATA 不作为这项修复的填充对象，仍保留原有后续处理。此行为是覆盖外外推，不是新增观测高程；旋转/跨 CRS 等路径不套用该策略。外推策略尚须更广泛输入和浏览器验收。
4. **Mercator 修正**：layer.bounds 转为经纬度；发现原生编码也曾把投影米当作经纬度生成 ECEF，因此保留投影 u/v 量化，并在 ECEF、包围球、法线计算前做逆投影。新增独立 pyproj ECEF 断言。
5. **Heightmap 范围**：Python 和原生入口均拒绝非有限值与 [-1000,12107] m 以外高程，提示使用 Mesh，消除 uint16 回绕。此范围针对当前 offset=1000、scale=5 编码。
6. **参数契约**：creation_options 非空、warp_memory 非 null、error_threshold 非默认值现在明确报错；不再静默忽略。schema 描述同步。它们仍属于“未实现并显式拒绝”，不能称为已实现 CTB 同等能力。
7. **断点与发布元数据**：`.tiling-state.json` 绑定源文件、外部概览和原生扩展 SHA256，以及影响编码的参数/引擎版本。不同数据/参数不得复用旧瓦片；无签名的历史目录需换新目录。已有输出要求 resume。恢复时检查 gzip、坐标编码、三角形/边界索引和扩展长度，损坏瓦片重算；开始后状态为 building，成功才写 complete。layer.json 改为原子写出，瓦片写出失败时不生成本轮 layer。

源文件必须在任务运行期间保持不可变；此签名机制不是输入快照，也未实现同一输出目录的跨进程排他锁。生产多任务应使用独立输出目录。恢复结构校验暂未把已知根 horizon 问题视为可自动修复；不能把“可恢复文件”当作完整精度/渲染验证。

## 实测结果

首个 n0e0 诊断：1220 张瓦片触发 5636 次采样，累计采样线程时间 21.27 s，原生编码约 0.85 s。首轮缓存及边缘支撑后仅采样 1220 次。诊断前/后墙钟分别为 6.53/2.45 s，但二者均含插桩，且后者同时改变边界行为；不能归结为缓存单项加速倍数。

最终比较：同一命名卷、4 CPU、4 线程、512 MiB 参数、Mesh/Geodetic/average、z10→z0、65 网格、quality=1、法线开启。每个样例/分支/轮次独立进程，三轮顺序运行，第二轮反转分支顺序，关闭插桩。容器启动不计时，未清系统缓存。当前计时包括源/概览/原生签名、最终状态和 layer 写出；main 是实际 CTB 命令，不含项目发布阶段。双方沿用各自既有写出实现：当前保留 fsync，未证明与 CTB 的断电持久性相同，因此这是产品实现比较，不是单纯算法内核比较。

| 样例 | main 中位秒 | 当前中位秒 | 当前/main | main 单进程 RSS MiB | 当前 MiB |
|---|---:|---:|---:|---:|---:|
| s85e80 | 1.808 | 1.975 | 1.09× | 319.09 | 247.93 |
| s5e130 | 1.570 | 1.992 | 1.27× | 227.71 | 169.69 |
| n0e0 | 2.020 | 2.111 | 1.04× | 325.35 | 252.69 |

RSS 为主/子进程中最大单进程高水位的三轮中位数，并非进程树同时内存之和。只测三个完整 TIFF，不能外推全目录或多任务吞吐。s5e130 尚未达到不超过 main 1.2 倍的目标；系统波动明显，应继续用成对测量验收。

三份样例分别生成 1164、1164、1220 个瓦片，集合与 main 一致；所有共同文件解码通过并有法线，三轮当前输出的路径及文件内容摘要一致。

独立表面比较（参考为原始 DEM 双线性高程，不是测量真值）：

| 指标 | s85e80 main/当前 | s5e130 main/当前 | n0e0 main/当前 |
|---|---:|---:|---:|
| 内部 RMSE m | 2.326 / 2.491 | 24.910 / 24.751 | 29.060 / 29.489 |
| 有效区边缘最大误差 m | 11.000 / 11.000 | 210.172 / 210.172 | 183.535 / 183.535 |
| 有效源覆盖内共享边最大差 m | 0.0816 / 0.0007 | 69.494 / 69.494 | 72.460 / 72.460 |

n0e0 历史有效边缘最大误差约 1940 m，本轮降为约 184 m；但内部误差并非所有指标均优于 main。覆盖外接缝另行保留：n0e0 当前全域接缝最大约 5191 m，而旧补零方案约 72 m。有效覆盖内最大约 72.46 m；两种口径不能混用。当前方案优先恢复有效区高程，外部过渡与发布边界仍需专项验收。

## 测试与生产状态

完整回归 **157 passed**，2 条第三方弃用提示。新增缓存只读/去重/淘汰/失败重试、边缘支撑不改内部孔洞、Heightmap 边界、参数拒绝、Mercator bounds/ECEF、恢复损坏瓦片、参数变更拒绝以及写盘失败不留发布 layer 的测试。基础静态检查通过。

**production_ready=false。以下门槛尚未通过：**

- 三样例各有一张空根瓦片 horizon 非有限，不能以结构解码成功代替剔除语义正确。大范围根瓦片可能不存在合适的单个 horizon 点；不能随意填 0。[Cesium 剔除源码](https://github.com/CesiumGS/cesium/blob/1.133/packages/engine/Source/Scene/GlobeSurfaceTileProvider.js)会使用该点决定整个瓦片可见性，需连同消费者验证。
- s5e130 耗时约 main 的 1.27 倍，未达到最终 1.2 倍目标。
- 共享边数十米极值、外推范围、内部/边缘误差容差尚未形成已接受的完整契约。
- Cesium 浏览器加载/定位/LOD/剔除未完成；Mercator 只有代码及独立数学断言，不是浏览器通过。
- 真正长稳多任务压力、进程树资源观测、取消及强制终止恢复、同目录互斥、全输入/mask/投影矩阵尚未完成。

下一轮顺序：空根 horizon 与消费者行为 → 固定最差共享边坐标逐阶段定位 → 完善输入拒绝矩阵/并发任务隔离 → s5e130 剩余耗时剖析 → 浏览器与长稳验收。以上是剩余工作，不是本轮完成声明。

本轮需要重建原生 wheel/镜像，旧扩展不支持只读缓存或 Mercator 新参数。已有预处理测试镜像中的原生二进制已重新构建；生产服务未替换。
